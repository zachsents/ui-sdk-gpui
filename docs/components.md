# Components

Names link to each component's page on the UI SDK site. `ui-sdk-color-picker` is re-exported as `ui_sdk::components::color_picker`. Run an example with `cargo run -p <crate> --example <file>` (`cargo run -p ui-sdk-toggle --example toggle_group`), or all of them with `cargo run --release -p ui-sdk-gallery`.

## Behaviors

The crates the components are built from, for components of your own. `crates/foundation/<name>` is `ui_sdk::foundation::<name>`; start with `ui-sdk-kernel`.

| Crate | What it has | Entry points | UI SDK docs |
| --- | --- | --- | --- |
| `ui-sdk-canvas` | Pan, zoom and connect ports on a large canvas. | `create_viewport`, `create_connect` | [Canvas](https://ui-sdk.dev/docs/core/behaviors/canvas) |
| `ui-sdk-color` | Parse, convert, mix and compare CSS colors. | `Color`, `parse_color`, `format_color`, `contrast_ratio` | [Colors](https://ui-sdk.dev/docs/core/color) |
| `ui-sdk-date` | ISO dates, month grids, formatting and parsing by locale. | `month_grid`, `add_days`, `format_date`, `parse_date` | [Dates](https://ui-sdk.dev/docs/core/date) |
| `ui-sdk-direct-manipulation` | Move, resize, swipe, hold, pick a point, draw ranges. | `create_move`, `create_resize`, `create_swipe_actions`, `bind_hold` | [Dragging and Resizing](https://ui-sdk.dev/docs/core/behaviors/direct-manipulation) |
| `ui-sdk-disclosure` | Collapsible's and Accordion's trigger and panel. | `Panel`, `PanelBinding`, `bind_trigger_element` | [Panels and Presence](https://ui-sdk.dev/docs/core/behaviors/motion#panels-and-presence) |
| `ui-sdk-drag-and-drop` | Sort, nest and move items by pointer or keyboard. | `bind_drag`, `create_reorder`, `create_tree_reorder`, `create_transfer` | [Drag and Drop](https://ui-sdk.dev/docs/core/behaviors/drag-and-drop) |
| `ui-sdk-focus` | Roving and grid tab stops, Tab order, focus recovery. | `RovingFocus`, `GridFocus`, `FocusRecovery`, `bind_tab_keys` | [Focus and Keys](https://ui-sdk.dev/docs/core/behaviors/focus) |
| `ui-sdk-forms` | Forms, labels, fieldsets, validation and reset. | `ElementInternals`, `Form`, `TextFieldApi`, `ToggleControl` | [Forms](https://ui-sdk.dev/docs/react/forms) (React) |
| `ui-sdk-gauge` | Progress's and Meter's value math and ARIA. | `gauge_settings`, `gauge_aria`, `indicator_style` | None |
| `ui-sdk-image` | Load and crop images. | `crop_image`, `load_image`, `use_image` | [Images](https://ui-sdk.dev/docs/core/image) |
| `ui-sdk-kernel` | Parts, controlled state, change details, the agent surface. | `Instance`, `Part`, `Controllable`, `Agent` | [Define a Primitive](https://ui-sdk.dev/docs/core/kernel/define-a-primitive), [Handle Changes](https://ui-sdk.dev/docs/core/kernel/handle-changes) |
| `ui-sdk-lists` | The listbox engine, virtualized lists, tree data. | `create_listbox`, `create_virtualizer`, `create_stick_to_bottom`, `create_tree_collection` | [Lists](https://ui-sdk.dev/docs/core/behaviors/lists), [Trees](https://ui-sdk.dev/docs/core/behaviors/trees) |
| `ui-sdk-motion` | Enter and exit transitions, panels, sheets, gesture physics. | `Presence`, `Panel`, `create_velocity_tracker`, `solve_spring` | [Transitions and Gestures](https://ui-sdk.dev/docs/core/behaviors/motion) |
| `ui-sdk-native` | The text field standing in for `<input>` and `<textarea>`, and selectable text standing in for a page's words. | `TextField`, `TextFieldOptions`, `TextFieldStyle`, `SelectableText`, `TextSelection` | None |
| `ui-sdk-number` | Format, parse, step and snap numbers by locale. | `format_number`, `parse_number`, `step_from_key`, `snap_to_step` | [Numbers](https://ui-sdk.dev/docs/core/number) |
| `ui-sdk-page` | The agent bridge, `observe`, history and undo. | `create_agent`, `agent_tools`, `observe`, `create_history` | [Observe](https://ui-sdk.dev/docs/core/observe), [Connect an Agent](https://ui-sdk.dev/docs/agents/connect-an-agent), [History and Undo](https://ui-sdk.dev/docs/agents/connect-an-agent/history-and-undo) |
| `ui-sdk-platform` | Announcements, direction, layers, placement, shortcut matching. | `live_regions`, `announce`, `position`, `push_layer` | [Platform](https://ui-sdk.dev/docs/core/platform), [Mobile](https://ui-sdk.dev/docs/core/mobile) |
| `ui-sdk-popups` | Popup presets: triggers, content, dismissal, modality, sheets. | `create_popup`, `PopupHost`, `popup_trigger`, `popup_content` | [Popups and Layers](https://ui-sdk.dev/docs/core/behaviors/popups) |
| `ui-sdk-preferences` | Saved choices, color scheme, pointer kind. | `Preference`, `ColorScheme`, `PointerKind` | [Preferences](https://ui-sdk.dev/docs/core/behaviors/preferences) |
| `ui-sdk-selection` | Selection, lasso, cell ranges, the active-item indicator. | `create_selection`, `create_lasso`, `create_cell_range`, `bind_indicator` | [Selection](https://ui-sdk.dev/docs/core/behaviors/selection) |
| `ui-sdk-shortcuts` | Shortcuts for the app or a part, scoped to open layers. | `register_shortcut`, `create_shortcuts`, `shortcut_slot`, `bind_part_shortcut` | [Shortcuts](https://ui-sdk.dev/docs/react/hooks/shortcuts) (React) |
| `ui-sdk-storage` | Local and session storage. | `init`, `create_local_storage`, `create_session_storage` | [Storage](https://ui-sdk.dev/docs/core/storage) |
| `ui-sdk-text` | Typeahead, search ranking, accessible names, input history. | `create_typeahead`, `fuzzy_score`, `match_ranges`, `create_input_history` | [Text](https://ui-sdk.dev/docs/core/text) |

Examples: `cargo run -p ui-sdk-native --example text_field`, `cargo run -p ui-sdk-native --example selectable_text` and `cargo run -p ui-sdk-page --example agent`.
